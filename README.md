## Sobre o projeto

Web App educacional desenvolvido para estudantes do Ensino Médio realizarem
diagnóstico territorial do próprio bairro, conectando vivência local aos
Objetivos de Desenvolvimento Sustentável.

**ODS 1 — Erradicação da Pobreza** · **OC10 — Tecnologias nas Práticas Educativas**  
Metodologia: CDIO (Conceber, Desenvolver, Implementar, Operar)

---

## Como usar

1. Acesse `index.html` para ver o relatório completo do projeto
2. Na seção **Web App**, baixe ou abra o aplicativo no celular
3. No app: toque no mapa para marcar pontos de atenção, registre com foto e voz
